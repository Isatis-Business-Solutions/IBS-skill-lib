# Language: Dutch

- **Je/jij/jullie** for colleagues, candidates and the network. For clients: follow the user or the existing
  relationship; when unsure in a first formal contact, use **u**, and ask the user if it matters.
- Plain Dutch over officialese: "via" not "middels", "over" not "inzake", "om" not "teneinde", "graag" not
  "gelieve".
- English terms only where the reader uses them too (dashboard, data lake); otherwise Dutch.
- Prefer verbs over nouns: "we analyseren" not "we voeren een analyse uit".
- Avoid clichés: "ontzorgen", "in de huidige snel veranderende wereld", "naar een hoger niveau tillen",
  "toegevoegde waarde", "synergie", "data is het nieuwe goud", "proactief meedenken".
- "We" for IBS as a team; "IBS" when the company is the subject for an outsider.
