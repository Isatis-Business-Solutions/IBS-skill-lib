# Excel workbooks (.xlsx)

Use an xlsx skill or library for the mechanics; this file gives the feel. Spreadsheets are for working, so
keep them light and readable, with IBS touches.

- **Font:** Poppins 10 pt if available; otherwise Arial 10 pt.
- **Title area (first rows):**
  - a dark band `#171717` across the used width, 2–3 rows high;
  - the title in cream (Poppins Light 16–18 pt);
  - `ibs-logo-on-dark-600.png` placed at the left, ≈ 3 cm wide.
- **Header row:** fill `#171717`, text `#FEF9ED` SemiBold. Or a lighter option: fill `#F2EBDA`, text
  `#171717` SemiBold, with a bottom border in `#F9C852` (2 pt). Freeze panes below the header.
- **Body:** white, thin horizontal borders `#E4DCC8`, no vertical borders. Optional banding `#FBF7EE`.
- **Numbers:** right-aligned, thousands separators, consistent decimals. Totals row SemiBold, top border
  `#171717`.
- **Accent:** highlight key cells with fill `#F9C852` and text `#171717` (sparingly). Positive `#7FB77E`,
  negative `#D9725B` for conditional formatting. Never yellow text.
- **Charts:** series order from `SKILL.md` (yellow first), no 3D, light gridlines, legend at the bottom.
- **Sheet tabs:** colour the main/summary tab `#F9C852`, the rest default.
